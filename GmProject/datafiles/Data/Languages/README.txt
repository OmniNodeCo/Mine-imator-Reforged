Mine-imator Reforged language files

Drop any .milanguage file into this folder and it appears under
Settings > Interface > Language automatically. Texts missing from a
translation are shown in English.

Bundled languages:

- english.milanguage - Mine-imator 2.0.2, by David, Nimi, mbanders
  (Continuation Build)
- chinese.milanguage - Simplified Chinese by 飒爽师叔 (vlssu),
  translated for Mine-imator 2.0.2 Continuation Build 1.0.13,
  via github.com/vlssu/Mine-imator-Chinese
- italian.milanguage - Italian by Lorenzo Giannini (Loweredgames),
  translated for Mine-imator 2.0.2,
  via github.com/Loweredgames/Mine-imator_traduzione_ita

A Chinese locale automatically switches the interface fonts to
bundled Noto Sans SC subsets (subset to the glyphs the interface
needs). Rare Chinese characters that are not part of the interface
translation may not display in text fields. Other languages use the
regular Latin fonts.

Languages marked for a newer or older version than this build work as
long as the text keys still match; everything the translation is
missing falls back to English. See log.txt (loading a language lists
the missing keys there) if you want to help complete a translation.
