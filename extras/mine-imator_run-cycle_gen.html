Mine-imator Run-Cycle Generator

Generate a realistic running cycle as a .miframes file: high knee drive, a flight phase where both feet leave the ground, pumping arms with bent elbows that open and close with the swing, forward lean and a strong up-and-down bounce. For walking use mine-imator_walk-cycle_gen.html in this folder.

Preview (side view, facing right)

Click the preview or press Space to pause, drag the slider to scrub. The ground moves at the ideal speed — if the feet slide while running, the speed you move the character with in Mine-imator does not match. Use the recommended speed below.

Settings

If it looks wrong in Mine-imator

The default Steve and Alex characters attach the head and arms to the body part, so they inherit its movement — this tool bobs only the body and legs for them. Only enable this if your custom rig keeps every part directly under the character root.

The rotation directions in Mine-imator cannot be tested from here. If the legs swing backward first or the knees bend the wrong way, tick the matching option and download again.

How to import into your project

  1. Download the file.
  2. Select your character in the timeline in Mine-imator, not an individual body part.
  3. Import the file as keyframes (.miframes). Body parts are matched by name: head, body, left_arm, right_arm, left_leg, right_leg — that covers Steve and Alex skins and rigs built like them.
  4. To run forward, move the character itself at the recommended speed. The animation runs in place so it does not overwrite your character's position.
